# ⚖️ NyayaPulse

> **A focused legal research desk for clearer questions, faster understanding, and better starting points.**

NyayaPulse is a modern legal research assistant that helps users explore legal principles, understand provisions, and turn complex questions into concise research notes. It combines a calm, distraction-free workspace with AI-powered responses for an approachable research experience.

## ✨ Highlights

- 🧭 **Research desk** — Ask legal questions from a simple, focused workspace.
- 📚 **Principle summaries** — Get clear starting points for foundational legal concepts.
- 📝 **Provision explanations** — Break down complex legal language into easier-to-follow explanations.
- ⚡ **Fast, conversational responses** — Submit a question and receive a focused research note.
- 🎨 **Thoughtful interface** — Clean typography, accessible controls, and a professional legal-workspace aesthetic.
- 🔎 **Research-first guidance** — Responses are intended to support research and should be checked against current law and authoritative sources.

## 🧠 How It Works

1. Enter a legal question in the research composer.
2. NyayaPulse sends the question to its AI-powered response layer.
3. Review the generated legal research note.
4. Use the response as a starting point for deeper research and source verification.

NyayaPulse uses the **Google Gemini API** to generate responses.

## 🛠️ Built With

- **Next.js** — Application framework
- **React** — Interactive user interface
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Styling foundation
- **Google Gemini API** — AI-generated legal research responses

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Run locally

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```



### Available commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm run start` | Start the production server |
| `npm run lint` | Check the codebase with ESLint |

## ⚠️ Important Note

NyayaPulse is a **research support tool**, not a substitute for qualified legal advice. Always verify responses against current legislation, case law, and other authoritative sources before relying on them.

## 🌱 Future Direction

NyayaPulse is designed to grow into a more complete legal research workspace with richer organization, saved research, and additional tools that help users move from an initial question to well-supported legal understanding.
